# 工程结构与行为约定

`State` 自动加载负责存档与设置；`SaveData.fresh()` 定义版本和初始数据。`world.gd` 只保留房间切换、交互、战斗命中、书籍和剧情流程的必要协调。16 个房间均是独立 `.tscn`，几何、出生点、交互文本和稳定 ID 在编辑器中可查看。

## 动作与残响

`ActionFrame` 每物理帧采集轴值、跳跃/松键、攻击、闪避、下方向和交互。玩家及主动残响共用 `player.gd.simulate()`，统一执行 CharacterBody2D 碰撞与动作状态。

`EchoClip` 保存房间、起始位置/速度、朝向、冷却等起始状态、当时是否持尺，以及最多 480 帧动作。播放时用当前世界重新模拟；不会按历史坐标拉动角色。起点形状查询失败不扣理智；新播放替换旧残响；离房间停止但保留片段。残响只能敲铃等明确允许的机关交互，不能拿书、对话、保存或再次录制。

`DeathImprint` 与 EchoClip 分离：只保存死亡前最多 360 帧视觉姿态、可达地面位置、实际理智债务和掉落书。亡响节点没有伤害或机关交互。每房间最多呈现最近三个，完整债务仍留在存档。

版本 2 另以 `recovery_point.tscn` 承担静止标记、书名、距离判断和交互。同位置 48 像素内合并显示；动画数量限制不作用于标记。`books` 清空表示已取回，`recovered` 表示债务已结清，两者独立；`State.collect_deaths()` 一次提交书籍归属、理智和回收状态，保存失败回滚。动画读取 `recovered` 后自行退出。

只把有足够边距、没有实体遮挡的根级 Floor 当作最近安全地面；不采用升降台或高台。钟庭只允许入口侧 550 像素内。每间房另有经过校验的 `RecoveryAnchor`；旧档无效点会迁至该锚点。现有地图的常规地面返程不依赖试读能力；将来新增可关闭门或能力专属区域时，需要同步补充可达性规则，不能把几何清空等同于任意关卡的图搜索。

`total_deaths` 与道具阶段永久保存。阶段 0 禁止主动残响；见库珀升到 1；六次死亡后再次会面升到 2。亡响按实际债务回收，零债务无增益。图书馆在标题背景载入时不会消耗赠送事件。

## 通路与剧情

- 开场：校门 → 前院 → 教学走廊 → 器材室 → 图书馆。
- 第一次回环：图书馆 → 旧书库 → 测量廊 → 教学走廊上层 → 图书馆。
- 因果教学：图书馆 → 回声教室 → 中央连廊；下层普通出口始终开放。
- 文理分支：中央连廊 → 机电间 / 安保室 / 维护通道 → 钟庭。
- 地下回环：钟庭 → 研究层 → 档案井 → 旧书库 → 图书馆。
- 收束判断：`archive` 在已归还书中，且 `boss_purified` 为真，在图书馆触发；取得两者的先后顺序不受限。

开发者额外路线说明：中央连廊末端三个金属配重，连续下劈回弹通往钟楼上层，再进入研究层；首次未净化守兽进入研究层会触发批注。金属平台采用单向顶面碰撞。该说明仅出现在开发文档和测试，不出现在任务提示。

## 存档可靠性

数据先写临时文件并 flush，再替换主文件。只把校验通过的主文件复制为备份。加载时依次校验主文件、备份，包含版本、书籍、房间、理智、亡响和动作片段；损坏 JSON 不产生引擎解析报错。明确开始新旅程会同时更新主档与备份。

永久道路、敌人净化、读过的便条、已探索房间和剧情标记保留。Boss 的未完成临时血量不保存。按键和系统界面不经过语言知识过滤。

版本 1 迁移前保留独立 `.v1-backup`，由历史亡响推导死亡次数。已归还、持有、遗落依次去重，避免同一本书拥有两份归属。进入房间后重验旧掉落点。保存前校验版本 2 数据；回收一笔已结清债务不会再次加理智。

## 编辑边界

`tools/`、`docs/`、`builds/`、`tests/output/` 有 `.gdignore`。游戏资源保持正常导入。Forge 插件位于 `addons/godot_forge/`；其运行时仅在有编辑器调试连接时激活，独立程序不开放远程控制服务。

`.tscn` 为编辑权威来源，全量 `build_content.py` 入口已停用。图书馆远景、透空窗墙、恢复书架、家具、地面和前景分别可改；`exploration_camera.gd` 的前视与垂直缓冲只影响显示，不参与残响物理。

图书馆 PackedScene 在主世界初始化时预载，避免首次进馆同步载入全部插画。数学读数与录制圆环由主场景的 `KnowledgeOverlay`（z=20）绘制，位于关卡几何之上、CanvasLayer 系统界面之下，不再被配重或平台覆盖。
