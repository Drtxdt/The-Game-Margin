# 首轮试玩记录

建议先直接玩，不先读架构文档中的额外路线。体验方向仍由实际试玩决定。

## 操作与因果

- 起停和跳跃是否容易控制？小跳与长跳是否自然？
- 攻击命中提示、闪避距离、受击反馈是否清楚？
- 第一次使用锚点时，你是否理解“动作重做，环境已经改变”？
- 不用残响继续探索时，是否感到自己在走有效路线？

## 地图与图书馆

- 从测量廊回到教学走廊时，是否认出这是之前的地方？
- 归还书、休息、换主修三处交互是否容易辨认？
- 取回地下档案后，图书馆的变化是否足够温暖、明显？
- 未归还书的遗落位置是否好找，能否顺路拿回？

## 守兽与节奏

- 是否能从前摇分辨冲锋、扑击、横扫、吼叫？
- 首次胜利尝试次数：____；钟庭累计时间：____。
- 哪一段在探索，哪一段只是在走路？请写房间名称。
- 开始时间：____；结束时间：____；暂停/离开时间：____。
- 首次主动残响发生在哪个房间：____；完成路线：物理 / 政治 / 维护。
- 全流程感受：迷路 / 恰好 / 过直；最想保留的一刻：____。

45–75 分钟是待验证目标。若实际内容不足，应增加有意义的空间理解、互动与发现，不靠减慢移动、强制死亡或重复跑图填充。
