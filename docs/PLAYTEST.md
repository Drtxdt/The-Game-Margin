# 首轮试玩记录

建议先直接玩，不先读架构文档中的额外路线。体验方向仍由实际试玩决定。

## 0.2 本轮优先记录

1. 带书正常探索，若死亡，记下能否从 HUD / 地图找到书包；不需要为了测试故意积累死亡。
2. 图书馆左右走动、起跳和归还书：人物与家具比例、脚下地面是否自然，镜头是否看得见落点。
3. 从图书馆出发，经过旧书库、测量廊、教学走廊返回：记录开始/结束时间，以及第一次停下寻找方向的位置。
4. 是否自行发现可选旧馆记录；观察读数是否帮助理解升降台；展开楼梯后是否知道它节省了哪段路。
5. 若正常游玩已累计六次死亡，回馆后再找亡响；记录赠送说明、回收提示是否明确。

## 操作与因果

- 起停和跳跃是否容易控制？小跳与长跳是否自然？
- 攻击命中提示、闪避距离、受击反馈是否清楚？
- 第一次使用锚点时，你是否理解“动作重做，环境已经改变”？
- 不用残响继续探索时，是否感到自己在走有效路线？

## 地图与图书馆

- 从测量廊回到教学走廊时，是否认出这是之前的地方？
- 归还书、休息、换主修三处交互是否容易辨认？
- 取回地下档案后，图书馆的变化是否足够温暖、明显？
- 未归还书的遗落位置是否好找，能否顺路拿回？
